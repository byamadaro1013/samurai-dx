# 内容証明で使えない文字一覧と置き換え表

監修:橋本祐弥 弁護士(東京弁護士会)【要確認:所属事務所名の表記とプロフィール文】
最終確認日:2026年10月15日

---

e内容証明で使えない文字は、下の表で探して、右の「置き換え例」に直してください。①は(1)に、㈱は(株)に、髙は高に。

e内容証明で使えるのはJIS第1・第2水準の文字だけで、表の文字はすべてその外にあります。〒、※、○、澤、齋は使えます。

## e内容証明で使えるのは「JIS第1・第2水準」の文字だけ

日本郵便の操作マニュアルでは、文字の範囲がこう決まっています。

「JISX0213-2004 で定める JIS 第一水準及び第二水準の文字を使用できます。」
「これら以外の文字(第三水準、第四水準、外字など)は入力をしないでください。」

第1・第2水準には、漢字6,355字と、ひらがな・カタカナ・全角英数字・よく使う記号が入っています。Windowsで変換できる文字はもっと多く、その差の部分が下の表です。

エラーが出たときの直し方の手順は[使用できない文字エラーの原因と直し方](/bakusokunaiyoushoumei/error/moji)にまとめています。

![使えない文字の置き換え例。①は(1)、㈱は(株)、㎡は平方メートル、ⅡはII、髙は高、﨑は崎](/assets/bakusoku/articles/moji-replace.svg)

メールやWebページから文章を貼り付けると、エンダッシュや絵文字が目に見えない形で紛れ込みます。

判定方法:Pythonで1字ずつ `euc_jp` に変換し、0xA1〜0xFEの2バイトに収まった文字だけをJIS X 0208(第1・第2水準漢字+非漢字)と判定し、区点から水準を出しました(区1〜8が非漢字、16〜47が第1水準、48〜84が第2水準)。`euc_jp` は補助漢字(JIS X 0212)や半角カナも変換してしまうのでそれは外し、〜/～のように同じ符号位置をWindowsが別の文字に割り当てているものはWindows(cp932)の区点でも確かめ、第3水準などの位置は `euc_jis_2004` で調べています(2026年10月15日)。

## 使えないと思われがちだが、実は使える文字

| 文字 | JISの位置 |
| --- | --- |
| 〒 | 2区9点(非漢字) |
| ※ | 2区8点(非漢字) |
| ○ ● ◎ | 1区91〜93点(非漢字) |
| □ ■ △ ▲ | 2区2〜5点(非漢字) |
| 〜(波ダッシュ U+301C) | 1区33点(非漢字) |
| ～(Windowsで打つ全角チルダ U+FF5E) | Windowsでは同じ1区33点【推測:下の段落参照】 |
| 〆 々 〇 ヶ | 1区25〜27点、5区86点(非漢字) |
| ≒ ≡ ∫ √ ∵ | 2区65〜73点(非漢字) |
| § † ♪ | 1区88点、2区86〜87点(非漢字) |
| 【】「」『』〔〕 | 1区44〜59点(非漢字) |
| ￥ ＄ ％ ＠ ＆(全角) | 1区79〜87点(非漢字) |
| 澤 櫻 國 齋 邊 邉 濱 槇 | 第2水準(区48〜84) |
| 斎 冨 曽 曾 槙 辻 葛 | 第1水準(区16〜47) |

〜と～は、見た目がほぼ同じでも文字コードが違います。Windowsで打つ「～」はU+FF5Eですが、これはJISの1区33点(波ダッシュ)をWindowsが別のコードに割り当てているだけで、JISの上では同じ字です。Windowsで「から」を変換して出るのはこちらの～なので、ふつうに打った～が通らないとは考えにくいです。【推測:公式に記載なし】 エラーが出たら「から」と書けば確実です。

## 窓口で出す紙の内容証明とは、文字の決まりが別

郵便局の窓口で紙の内容証明を出すときは、日本郵便の「ご利用の条件等」のページにある決まりに従います。使える文字は仮名、漢字、数字、括弧、句読点などで、「英字(固有名詞に限ります。)」とあります。字数も、縦書きなら「1行20字以内、1枚26行以内」です。e内容証明のマニュアルにはこの字数・行数の決まりは見当たらず、決まっているのはWordの雛形、余白、フォント、JIS第1・第2水準の文字です。英字を固有名詞に限るという決まりも、e内容証明のマニュアルやFAQには見当たりませんでした。【推測:e内容証明で英字を使った場合の扱いは公式に明記なし】 紙用に1行20字で組んだ文書をe内容証明の雛形に貼ると、行の折り返しが変わるので、ページ数と余白は見直しになります。

紙なら1枚ずつ数え、e内容証明なら文字を照合する。どちらも手作業です。バクソクなら、差出人と受取人を選び、文書を添付して、内容を確認して決済するまでの3操作、約2分(開発者の実測)で済みます。

## よくある質問

**Q. 旧字体は内容証明で使えますか?**
A. e内容証明では、第1・第2水準に入っている旧字体なら使えます。日本郵便のFAQでも「外字/旧字体は使えますか?」という質問に、第1・第2水準の範囲内であれば使えると答えています。澤、櫻、國、齋は使えて、髙、﨑、德は使えません。

**Q. どの文字が使えないか、Wordで見分ける方法はありますか?**
A. MS-IMEで変換したとき候補の横に「環境依存」と出る字は、表の字とかなり重なります。ただ、IMEの表示とe内容証明の基準は同じものではないので、上の表と照合するのが確実です。【推測:IMEの表示と規定の範囲は未照合】

**Q. 事務所の何人かで、内容証明の作成と送付を分担しています。**
A. バクソク内容証明は、同じ事務所の中で共有できます。WindowsとMacのどちらでも使え、最後の差出ボタンは送る人が自分で押します。

**Q. 「文書確認」画面で字の形が違って見えます。**
A. 日本郵便のFAQでは「「文書確認」画面で表示された内容で印字されますので、その画面で確認してください。」と案内されています。画面で見たとおりの字で相手に届きます。

## 1字ずつ照合するのが面倒なら

![バクソク内容証明のアプリ画面。左に案件一覧、中央に入力欄、右に日本郵便の公式画面が並ぶ](/assets/bakusoku/app-screen.png)

ここまで読んで、「59字を毎回目で探すのか」と思った方もいると思います。

e内容証明は、宛先を打ち込み、文書をアップロードして、文字や余白でエラーが出たら直して最初から。1通出すのに7分ほどかかります。代行に頼めば楽ですが、1通1万〜2万円以上かかります。

**バクソク内容証明**は、e内容証明の入力と画面の移動を代わりに進めるパソコン用のアプリです。

- 操作は3つ。文書を添付する、差出人と受取人を選ぶ、内容を確認して決済ボタンを押す
- 決済まで約2分(開発者の実測)
- 送る前に、文書が日本郵便の規定に合っているかを判定
- 最後の差出ボタンは自分で押す。勝手に送られることはありません
- 文書はパソコンの中で処理し、外部のサーバーには送りません
- WindowsとMacで使えます
- 料金は9,800円(税込)。同じ事務所の中で共有できます【要確認:定価11,800円との関係、買い切りかどうか】

代行に1通頼むのとほぼ同じ金額です。
