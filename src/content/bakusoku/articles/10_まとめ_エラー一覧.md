# e内容証明のエラー一覧と直し方

監修:橋本 〇〇 弁護士(〇〇法律事務所)【要確認:表記とプロフィール文を受領】
最終確認日:2026年10月15日

---

e内容証明のエラーは、ほとんどが**Wordの文書側**で起きています。画面に出たエラー文を下の一覧で探して、その見出しの直し方を試してください。

どのエラーでも、迷ったら最後は同じです。日本郵便の雛形をダウンロードし直して、本文をメモ帳経由で貼り直す。日本郵便のFAQでも、図形、白紙ページ、イメージファイル作成など、多くのエラーでこの作り直しが案内されています。

![エラーが直らないときの作り直し手順。雛形をダウンロードし直し、本文をメモ帳に貼って書式を消し、雛形に貼って.docxで保存する](/assets/bakusoku/articles/rebuild-flow.svg)

## エラー文の一覧

| 画面に出る文言 | 原因 | 詳しい直し方 |
| --- | --- | --- |
| 余白部分に通信文がある(余白のエラー) | 下7cm(縦書きは左7cm)の余白に文字がはみ出している | [余白エラー](/bakusokunaiyoushoumei/error/yohaku) |
| 使用できない文字がある | ①、髙、㈱などJIS第1・第2水準にない文字 | [使用できない文字エラー](/bakusokunaiyoushoumei/error/moji) |
| 文字以外の図形等の情報があります。文字のみで作成してください。 | 表、画像、図形などが入っている | [図形等の情報エラー](/bakusokunaiyoushoumei/error/zukei) |
| 文字の重なりを検出しました。 | 貼り付けた書式や図形で文字が重なっている | [文字の重なりエラー](/bakusokunaiyoushoumei/error/kasanari) |
| 白紙のページがあります。白紙ページは削除してください。 | 末尾の空行や改ページで白紙ができている | [白紙ページエラー](/bakusokunaiyoushoumei/error/hakushi) |
| ページ数オーバーです。5ページまでで作成してください。 | 6ページ以上になっている | [ページ数オーバー](/bakusokunaiyoushoumei/error/page) |
| アップロードされたファイルに問題が発生したため、処理を中止しました。 | 3MB超、.doc形式など | [アップロードできない](/bakusokunaiyoushoumei/error/upload) |
| イメージファイルの作成ができませんでした。 / 処理を中断しました。 | 混雑など一時的なもの、または文書の崩れ | [イメージファイル作成エラー](/bakusokunaiyoushoumei/error/image) |
| ログインできない、既にログインしている | 同じIDで同時にログインしている | [ログインできない](/bakusokunaiyoushoumei/error/login) |

余白と使用できない文字は、エラー文の正確な文言を日本郵便の公開資料で確認できていません。原因は公式の規定から書いています。【推測:画面の文言】

## 余白のエラー:下7cmにはみ出している

横書きなら上・左・右は1.5cm以上、下は**7cm以上**。縦書きなら左が7cmです。全ページ同じ設定にする必要があり、マニュアルには「余白部分に通信文があるとエラーになります」とあります。

最後のページの末尾が下の余白に入り込むのがいちばん起きやすい形です。Wordの「レイアウト」→「余白」→「ユーザー設定の余白」で、設定対象を「文書全体」にして直します。

→ [余白エラーの原因と直し方](/bakusokunaiyoushoumei/error/yohaku)

## 使用できない文字のエラー:①や髙は使えない

使える文字はJIS第1・第2水準まで。第3・第4水準と外字は使えません。

引っかかりやすいのは、丸数字(①②)、ローマ数字(Ⅰ Ⅱ)、㈱、㎡、人名の旧字体(髙、﨑)です。①は(1)に、髙は高に置き換えます。人名を変えてよいかは依頼者と確認してください。

→ [使用できない文字エラーの直し方](/bakusokunaiyoushoumei/error/moji) / [使えない文字の一覧と置き換え表](/bakusokunaiyoushoumei/moji)

ここまでの2つは、アップロードしてみるまで気づけないのが困るところです。[バクソク内容証明](/bakusokunaiyoushoumei)は、送る前に自分のパソコンの中で、文書が日本郵便の規定に合っているかを判定します。【要確認:使えない文字の判定に対応しているか】

## 「文字以外の図形等の情報があります」:表や画像が入っている

e内容証明は、画像・表・図形を使えません。目に見える表や画像だけでなく、他の文書から貼り付けたときに一緒に入ったものでも止まります。

日本郵便のFAQでは、本文をメモ帳に貼っていったん文字だけにし、雛形に貼り直す方法が案内されています。

→ [図形等の情報エラーの直し方](/bakusokunaiyoushoumei/error/zukei)

## 「文字の重なりを検出しました」:書式の持ち込み

図形エラーと同じく、貼り付けで持ち込んだ書式が原因になることが多いエラーです。公式の対処も同じで、メモ帳経由でテキストだけにして雛形に貼り直します。

→ [文字の重なりエラーの直し方](/bakusokunaiyoushoumei/error/kasanari)

## 「白紙のページがあります」:末尾の空行と改ページ

最後の行のあとに残った空行や改ページで、白紙のページができています。白紙がないのに出る場合は、変換のときに改行がずれてレイアウトが崩れている可能性があると、日本郵便のFAQに書かれています。

マニュアルの差込差出しの章には「1行以上の余裕がないと白紙エラーまたはページ数オーバーエラーが発生する原因」ともあります。ふつうの差出しでも、ページの最後まで詰めて書かないのが安全です。【推測:通常の差出しについての明記はない】

→ [白紙ページエラーの直し方](/bakusokunaiyoushoumei/error/hakushi)

## 「ページ数オーバーです」:5ページまで

1通は5ページまでです。5ページ以内に収めたつもりでも、変換でずれて6ページ目ができるとこのエラーになります。

→ [ページ数オーバーの直し方](/bakusokunaiyoushoumei/error/page)

## 「アップロードされたファイルに問題が発生したため、処理を中止しました」:容量と形式

まず確認するのは、ファイルが3MB以内か、形式が.docxか(.docは不可)の2点です。ファイル名は拡張子を除いて全角20文字以内という決まりもあります。

雛形を使わずに作った文書も受け付けてもらえません。

→ [アップロードできないときの直し方](/bakusokunaiyoushoumei/error/upload) / [雛形(テンプレート)の正しい使い方](/bakusokunaiyoushoumei/error/hinagata)

内容証明を毎週のように出していると、この確認を1通ごとに繰り返すことになります。バクソクなら、文書を添付して差出人と受取人を選べば、規定に合っているかの判定まで進みます。

## 「イメージファイルの作成ができませんでした」「処理を中断しました」:時間をおく

どちらも、日本郵便のFAQではまず「もう一度」が案内されています。「処理を中断しました」はサーバが混雑している可能性があるので、時間をおいてから申し込み直します。

何度やっても同じなら文書側の問題です。雛形から作り直してください。

→ [イメージファイル作成エラーの直し方](/bakusokunaiyoushoumei/error/image)

## ログインできない:同じIDで同時に入れない

1つの会員IDで、同時に複数の画面からログインすることはできません。事務所で1つのIDを共有していると、誰かが入ったままだと入れません。使っている画面でログアウトしてから入り直します。

→ [ログインできないときの直し方](/bakusokunaiyoushoumei/error/login)

## 差込差出し(CSV)のエラー

複数の宛先にまとめて送る「差出し」機能を使っているときのエラーです。

- 「差込フィールドが設定されています。」:差込フィールドが残っています。削除して申し込み直します。使った覚えがなければ、過去の差出しの履歴がファイルに残っているので、雛形から作り直します。
- 「ダブルクォーテーションが1個(または奇数個連続で)使用されています。」:CSVの中の「"」は2個続けて入力します。
- 「イメージファイル作成エラー通知」というメールが届いた:CSVとWordの差込項目名が一致しているか、Wordにパスワードをかけていないかを確認します。

## Macで使うときの注意

e内容証明で使えるフォントは、MS明朝、MS P明朝、MSゴシック、MS Pゴシックの4つです。Macにはこれらが入っていないことがあり、別のフォントに置き換わってエラーになる場合があります。【推測:Mac環境は未検証】

バクソク内容証明はWindowsとMacの両方で動きます。

## よくある質問

**Q. エラーが出たら、最初からやり直しですか?**
A. 文書を直して、もう一度アップロードします。宛先などの入力をやり直す必要があるかは、エラーが出た画面によって変わります。【推測:画面ごとの挙動は未確認】

**Q. どうしても直らないときは?**
A. 日本郵便のFAQページに、e内容証明のヘルプデスクが案内されています。

**Q. 期限が迫っていて、エラーを直している時間がありません。**
A. 郵便局の窓口から紙で出す方法もあります。時効など期限の数え方は事案によって違うので、早めに弁護士に相談してください。【要監修】

## エラーと付き合わずに済む方法

![バクソク内容証明のアプリ画面。左に案件一覧、中央に入力欄、右に日本郵便の公式画面が並ぶ](/assets/bakusoku/app-screen.png)

ここまで並べてみると、e内容証明のエラーは種類が多く、しかも送る直前にならないと出ません。出すたびにこの一覧を見に来るのか、と思った方もいると思います。

代行に頼めば1通1万〜2万円以上かかります。

**バクソク内容証明**は、e内容証明の入力と画面の移動を代わりに進めるパソコン用のアプリです。

- 操作は3つ。文書を添付する、差出人と受取人を選ぶ、内容を確認して決済ボタンを押す
- 決済まで約2分(開発者の実測)。これまでの手作業では約7分
- 送る前に、文書が日本郵便の規定に合っているかを判定
- 最後の差出ボタンは自分で押す。勝手に送られることはありません
- 文書はパソコンの中で処理し、外部のサーバーには送りません
- 料金は9,800円(税込)。同じ事務所の中で共有できます【要確認:定価11,800円との関係、買い切りかどうか】

代行に1通頼むのとほぼ同じ金額です。

→ [バクソクで5分で送る](/bakusokunaiyoushoumei)
