# 「ページ数オーバーです」の原因と直し方

監修:橋本祐弥 弁護士(東京弁護士会)【要確認:所属事務所名の表記とプロフィール文】
最終確認日:2026年10月15日

---

「ページ数オーバーです。5ページまでで作成してください。」と出たら、Wordの画面右下で**ページ数**を見てください。6ページ以上なら、本文を削って5ページに収めます。

5ページ以内なのに出る場合は、アップロード後の変換で改行がずれて、6ページ目ができています。最後のページの末尾をあければ直ることが多いです。

![エラー表示のイメージ: ページ数オーバーです。5ページまでで作成してください。](/assets/bakusoku/articles/dialog-page.svg)

## 決まりは「5ページまで」。1行の字数や1ページの行数の決まりは見当たらない

日本郵便の操作マニュアルでは、e内容証明の文書は「最大5枚まで」です。ページ数の上限はこれだけで、規定されているのは次の項目です。

| 項目 | e内容証明の規定 |
| --- | --- |
| ページ数 | 5ページまで |
| 文字の大きさ | 10.5ポイント以上145ポイント以下 |
| フォント | MS明朝、MS P明朝、MSゴシック、MS Pゴシック |
| 余白(横書き) | 上・左・右1.5cm以上、下**7cm以上** |
| 余白(縦書き) | 上・下・右1.5cm以上、左7cm以上 |

「e内容証明 文字数 行数」で調べる方が多いのですが、e内容証明の操作マニュアルとFAQには、1行の字数や1ページの行数の決まりは書かれていません。

紙で窓口から出す内容証明には、日本郵便のページに「1行20字以内、1枚26行以内」(縦書き)などの決まりがあります。横書きなら「1行13字以内、1枚40行以内」「1行26字以内、1枚20行以内」も選べます。これは窓口に持っていく謄本の決まりで、e内容証明の規定とは別です。【推測:e内容証明の資料に、紙の字数・行数の決まりを当てはめる記載がないため】

困るのは、6ページ目ができているかどうかが、郵便局の画面でアップロードするまでわからないことです。宛先を打ち込んで、文書を選んで、エラー。削ってまた最初から入力します。[バクソク内容証明](/bakusokunaiyoushoumei)は、差出人と受取人を一度登録すれば選ぶだけなので、やり直しのたびに住所を打ち直す手間がなくなります。【要確認:差出人・受取人を保存して選べる仕様か】

![e内容証明の文書は5ページまで。6ページ目があるとページ数オーバーのエラーになる](/assets/bakusoku/articles/page-over.svg)

## エラーになる原因は2つ

### 1. 本文が6ページ以上ある

いちばん多いのはこれです。下の余白が7cmあるので、A4の1ページに入る量は普段のWord文書よりかなり少なくなります。いつもの感覚で書くと、4ページのつもりが6ページになります。

### 2. 5ページ以内なのに、変換で6ページ目ができた

日本郵便のFAQでは、5ページ以下なのにこのエラーが出る場合、処理の途中で改行が追加されてレイアウトが崩れている可能性があるとしています。対処は改ページ位置の調整か、文書の作り直しです。

5ページ目の一番下まで本文が詰まっていると起きやすいです。マニュアルの差込差出しの章にも、最終ページの最終行に「1行以上の余裕」がないと「白紙エラーまたはページ数オーバーエラー」の原因になると書かれています。差込差出し以外でも、末尾を詰めすぎないほうが安全です。【推測:通常の差出しの章には同じ記載がない】

## 5ページに収める直し方

### 文字を小さくする、余白を狭くする、は使えない

文字は10.5ポイントが下限です。余白も上の表の数字より狭くできません。Wordでよくやる「文字を9ポイントにする」「余白を狭くする」は、どちらも別のエラーになります。

行間を詰める方法も、雛形の書式を変えることになるので勧めません。FAQには「雛形ファイルの書式は変更しないでください」とあります。【推測:行間の変更そのものがエラーになるかは公式資料で確認できていない】

### 本文を削る

残る方法は、文面を短くすることです。

1. Wordの「表示」→「ナビゲーション ウィンドウ」でページ数を確認する
2. 経緯の説明で、日付と金額以外の繰り返しを削る
3. 「つきましては」「なお」など、段落の頭のつなぎ言葉を減らす
4. 1行だけ次のページにはみ出している段落を、言い回しで1行短くする
5. 最後のページの末尾に、1行以上の空きがあるか見る

請求の根拠や期限の書き方を削るときは、内容が変わらないか弁護士に確認してください。【要監修】

### 5ページ以内なのに出るときは、末尾をあけて改ページを見直す

1. 「ホーム」→「編集記号の表示/非表示」(¶のボタン)を押す
2. 最後の行のあとに続く空の改行を消す
3. 5ページ目の一番下まで本文がある場合は、1〜2行削って余裕を作る
4. 手で入れた改ページ(「改ページ」と表示される線)があれば、位置を見直す

これで直らなければ、日本郵便のサイトから雛形をダウンロードし直し、本文をいったんメモ帳に貼ってから雛形に貼り付けて作り直します。

ここまでやって再アップロードし、また別のエラーが出ると、入力からもう一度です。バクソクは送る前に、文書が日本郵便の規定に合っているかを判定するので、郵便局の画面で何度も往復せずに済みます。【要確認:判定対象にページ数を含むか】

## ページ数と一緒に引っかかりやすいエラー

- 「白紙のページがあります。白紙ページは削除してください。」 末尾の空行が原因になりやすく、ページ数オーバーと同じところで起きます →[白紙ページのエラー](/bakusokunaiyoushoumei/error/hakushi)
- 余白のエラー 下7cmに本文がはみ出すと止まります →[余白エラー](/bakusokunaiyoushoumei/error/yohaku)
- 文字を小さくして収めようとした結果のフォント違い →[エラー一覧](/bakusokunaiyoushoumei/error)

## よくある質問

**Q. 差出人と受取人の住所で、ページが増えることはありますか?**
A. マニュアルには、差出人と受取人の住所・氏名が最終ページに自動で印字され、「料金の計算対象となる電子内容証明文書の枚数は、Word で作成されたページ数よりも増える場合があります」とあります。料金のページ数が増えるという説明で、5ページの上限に含まれるかは書かれていません。【推測】

**Q. 6ページ以上になる内容は、どうすればいいですか?**
A. 2通に分ける方法と、窓口から紙で出す方法があります。分けた場合の法的な扱いは事案によるので、弁護士に確認してください。【要監修】

**Q. 何ページになるか、アップロード前に確かめる方法はありますか?**
A. Wordの印刷プレビューで見るのが基本です。ただ変換でずれることがあるので、5ページ目は余裕を残してください。送る前に規定を判定するアプリ「[バクソク内容証明](/bakusokunaiyoushoumei)」もあります。

## 毎回ページ数を合わせるのが面倒なら

![バクソク内容証明のアプリ画面。左に案件一覧、中央に入力欄、右に日本郵便の公式画面が並ぶ](/assets/bakusoku/app-screen.png)

ここまで読んで、「削って、プレビューして、アップロードして、また削るのか」と思った方もいると思います。

e内容証明は、宛先を打ち込み、文書をアップロードしてエラー、直してもう一度。1通出すのに7分ほどかかります。代行に頼めば楽ですが、1通1万〜2万円以上かかります。

**バクソク内容証明**は、e内容証明の入力と画面の移動を代わりに進めるパソコン用のアプリです。

- 操作は3つ。文書を添付する、差出人と受取人を選ぶ、内容を確認して決済ボタンを押す
- 決済まで約2分(開発者の実測)
- 送る前に、文書が日本郵便の規定に合っているかを判定
- 最後の差出ボタンは自分で押す。勝手に送られることはありません
- 文書はパソコンの中で処理し、外部のサーバーには送りません
- 料金は9,800円(税込)。同じ事務所の中で共有できます【要確認:定価11,800円との関係、買い切りかどうか】

代行に1通頼むのとほぼ同じ金額です。

→ [バクソクで5分で送る](/bakusokunaiyoushoumei)
